# Netflix Movies and TV Shows - Exploratory Data Analysis

## 📌 Project Overview

This project performs Exploratory Data Analysis (EDA) on a Netflix Movies and TV Shows dataset.

The main goal is to analyze the dataset, identify patterns and trends, and discover important factors related to Netflix content.

## 🎯 Objectives

- Analyze the Netflix dataset
- Identify missing values
- Perform statistical analysis
- Compare Movies and TV Shows
- Analyze content by release year
- Identify top content-producing countries
- Analyze popular genres
- Analyze content ratings
- Identify correlations between numerical features
- Present important insights using visualizations

## 🛠️ Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn

## 📊 Analysis Performed

### 1. Movies vs TV Shows

Analyzed the distribution of Movies and TV Shows available on Netflix.

### 2. Release Year Analysis

Analyzed the number of Netflix titles released across different years.

### 3. Top Countries

Identified the countries producing the highest number of Netflix titles.

### 4. Top Genres

Analyzed the most common genres available on Netflix.

### 5. Content Ratings

Analyzed the distribution of different content ratings.

### 6. Correlation Analysis

Used a correlation heatmap to understand relationships between numerical variables.

## 📈 Visualizations

The project contains the following visualizations:

- Movies vs TV Shows
- Netflix Titles by Release Year
- Top 10 Countries
- Top 10 Netflix Genres
- Top Content Ratings
- Correlation Heatmap

## 🔍 Key Insights

- Netflix contains both Movies and TV Shows, with Movies forming a large portion of the catalog.
- Netflix content has increased significantly in recent years.
- A small number of countries contribute a large amount of Netflix content.
- Drama and other popular genres make up a significant portion of the catalog.
- The dataset contains missing values in several columns, which is an important part of the data-cleaning process.
